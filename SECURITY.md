# Security

ClaudeBar handles a claude.ai login, so security reports matter.

Please report vulnerabilities privately through GitHub: open the **Security** tab of this repository
and choose **Report a vulnerability**. Please do not open a public issue for a security problem, and never
paste a real session key or cookie into any issue.

What is in scope: anything that could expose a user's login, read data ClaudeBar should not read,
or send data anywhere other than claude.ai.
